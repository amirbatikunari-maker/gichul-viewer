# v315 — 본문저장 디버그 · «Q1. 질문» 모양

## 바뀐 모양
- «📌 저장한 Q&A N» 머리줄 없앰 → 쉬운 풀이 아래에 **Q1. 질문내용 · Q2. 질문내용 …** 이 바로 한 줄씩
- 줄을 누르면 답(A)이 펼쳐짐 · ▸ 표시가 돌아감
- 질문이 짧으면 펼쳤을 때 질문을 또 적지 않음 (길거나 여러 줄일 때만 본문에 Q 전체)
- 사람이 펼쳐 둔 항목은 화면이 다시 그려져도 펼친 그대로

## 디버그에서 찾아 고친 것
- **다른 기기에서 쌓은 것이 새로고침 전까지 안 보이던 것** → 1분마다 · 창으로 돌아올 때 다시 받음
- **두 기기에서 따로 저장하면 한쪽이 덮어써 사라질 수 있던 것** → 올리기 전에 서버 것과 합침 (항목 id 로)
  - 지운 항목은 «지운 표시» 를 남겨 옛 기기가 되올려도 안 살아남
  - 고친 항목은 나중에 고친 쪽이 남음
- **SQL 전(qa 칸 없음)이면 «이 기기에만 저장» 안내가 안 뜨던 것** → 처음 한 번 뜸
  - SQL 을 돌리면 1분 안에 이 기기에 쌓인 것을 알아서 올림
- **AI 가 답을 쓰는 중에 저장하면 답이 잘리던 것** → 쓰는 중에는 저장 단추 막고 안내

## 확인한 것 (테스트)
- 저장 → Q1 · 두 번째 → Q2 아래로 · 접은 것 유지 · 고치기 · 지우기(번호 당겨짐) · 서버 반영
- 두 기기 합치기 · 지운 것 안 살아남 · qa 칸 없을 때 · 한눈에 보기에서 그 문항에 저장 · 필기 화면 안내
