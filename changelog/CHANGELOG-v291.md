# v291 — 유형 쪽지: 찾은 목록을 보면서 연달아 연동 · 보이는 것 한 번에 연동

고친 파일: `practice.html` · `sw.js` · `index.html`

- 본문으로 찾은 뒤 «연동» 을 눌러도 찾은 말·목록·스크롤 자리가 그대로 남음
  → 아래로 내려가며 하나씩 바로 «연동» (눌린 것은 «같음» 으로 바뀜)
  - 번호로 찾은 경우는 예전처럼 칸을 비움
- 목록 머리 «＋ 보이는 N개 모두 연동» — «같음» 아닌 것을 한 번에 (요청 한 번)
  - 이 문제에 유형이 없으면 이름을 한 번만 물음
  - 다른 유형이 이미 붙은 문항은 건너뜀 (말없이 합치지 않음) — 하나씩 «연동» 을 누르면 합칠지 물음
- 쪽지를 다시 그려도 보던 스크롤 자리 유지
