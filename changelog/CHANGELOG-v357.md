# v357 — 해설 돌리기: «목록 전체» 에서 해설 없는 것만 고르기

- 범위가 «목록 전체» 일 때 위 단추가 «목록 전체 · 해설 없는 것만» / «목록 전체 · 다 다시» 로 바뀜
  - 해설 없는 것만 = 이미 해설 있는 문항은 건너뜀 (아래 «이미 해설 있는 것도 다시 쓰기» 체크가 꺼짐)
  - 다 다시 = 해설 있는 것도 다시 씀 (체크가 켜짐)
  - 켜진 쪽이 파랗게 표시 · 합계에 «(해설 없는 것만)» 이 붙음
- 다른 범위(이 회차·고른 번호)에서는 예전처럼 그 회차의 번호를 고르는 단추
- 시험(헤드리스 크롬, 5문항 중 2개 해설 있음): 해설 없는 것만 → 3문항 · 다 다시 → 5문항
