# v358

## 회독
- **버그 수정**: 카드 자체에 `data-result` 표시가 붙어 있어서, 카드 안을 **아무 데나** 누르면 회독이 +1 되고 있었음 (p07·p09·p06).
  - 그래서 ＋를 누르면 2씩 오르고, −를 누르면 −1 다음 +1이 돼서 그대로였음.
  - 이제 ✓/✕ 단추만 셈.
- 답안 이름줄 회독 **＋** → 회독 +1 하고 **다음 번호로** 넘어감 (일반 보기·한눈에 둘 다). **−**는 숫자만 줄이고 넘어가지 않음.
- 회독 단추를 **꾹 (0.7초)** 누르면 그 문항의 회독이 초기화됨 (0회독, 맞힘·틀림도 0).
  - 해당 단추: 답안 이름줄의 −/숫자/＋, 한눈에 머리줄의 «＋ 회독», 일반 보기 머리줄의 «회독».

## 쉬운 풀이 칸
- 줄간격 ＋/−가 이제 **글 줄**에도 먹음. 전에는 식 상자에만 먹어서, 글만 있는 해설에서는 아무것도 안 바뀌었음.
- 한눈에서도 «줄간격» 글자가 다시 보임.
- «◫ 원래대로» 단추 → **[이지뷰 | 원래대로] 토글**. 지금 보고 있는 쪽이 진하게 표시됨.
- **펼치기는 기본 OPEN**. 다른 문항으로 넘어가도 펼친 채로 있음.
- 유형 고르기 드롭다운을 없애고 **«해설 AUTO»** 표시만 둠. 문항마다 골라 두었던 유형도 모두 지움 (늘 AI가 판단).
- **상세 Opus / 상세 Sonnet을 동시에 진행**할 수 있음.
  - 누르고 다음 문항으로 넘어가 또 누르면 같이 돎. 최대 6개까지.
  - 같은 문항을 두 번 돌리는 것은 막음.
  - 오른쪽 아래에 «✎ 해설 N개 동시 진행 중 — 3번 Opus · 4번 Sonnet» 이 표시됨.
  - 단추는 문항별로 «뽑는 중… N초»를 보여 줌.

## 한눈에 머리줄
- 가-/가+ 단추와 글자 끌기막대를 없앰 → **해설 글자 − 가 9pt ＋** (0.5pt씩, 5~15pt).
- 수식 크기: **− √100% ＋**. 5~10%씩 고르게 바뀌고 (50~200%) 지금 크기가 표시됨.
- 두 −/＋ 모두 꾹 누르면 계속 바뀜.
- «📖 해설만» 단추를 없앰. 켜진 채 저장돼 있던 상태도 끔.
