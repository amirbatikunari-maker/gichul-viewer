# v305 — 한눈에 ✓/✕ 가 «카드가 화면에 없어 기록하지 못했습니다» 로 막히던 것

고친 파일: `practice.html` · `sw.js` · `index.html`

- 한눈에의 ✓ 맞음 · ✕ 틀림은 목록 카드의 단추를 대신 눌러 기록했는데, 목록은 지금 문항 앞뒤 12장만 그림
  → 미니맵·분류판·유형 쪽지로 먼 문항을 열거나, 거르기·중복 묶기로 접힌 문항이면 카드가 없어 기록이 안 됐음
- 카드가 없으면 기록 함수로 바로 적음 (같은 문제 연동 · 기기 동기화 그대로) → 다음 문항으로
- 확인: 목록에 없는 문항에서 ✕ 틀림 → 알림 없이 기록 · 다음 문항 · 기능 회귀 25개 통과
