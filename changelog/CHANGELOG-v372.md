# v372

- 한눈에 문제 줄 **[이지뷰 | 원래대로]**를 원래 뜻인 «칸 배치» 바꾸기로 되돌림.
  - 이지뷰: 왼쪽에 문제·답안을 위아래로, 오른쪽에 쉬운 풀이를 길게 (2단).
  - 원래대로: 문제 | 답안 | 쉬운 풀이를 나란히 (3단). 칸 사이를 끌어서 폭 조절.
  - v358~v371 동안 이 단추가 «쉬운 풀이 정리 보기 켜고 끄기»에 잘못 연결돼 있었음.
- «정리 보기» 켜고 끄기는 쉬운 풀이 줄의 작은 **◫ 정리 켬 / 끔** 단추로 옮김.
- 단축키 **V 두 번** = 이지뷰 ↔ 원래대로 (칸 배치).
- 일반 보기 카드에서는 칸 배치 단추를 뺌. 한눈에에만 해당되는 기능이라서.
