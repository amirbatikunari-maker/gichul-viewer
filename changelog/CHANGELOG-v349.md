# v349 — 📐 공식 창: 한글로만 쓴 식도 잡음 + BIL·절연계급 공식

## 바뀐 것
- 기호 없이 한글로만 쓴 식도 «해설에 쓴 식» 으로 잡음
  - 예: 절연계급 = (BIL − 50)/5 · 공칭전압 = 절연계급 × 1.1
  - 거르는 것: 숫자 대입식(등호 2개 이상 · 오른쪽에 변수 없음), 단위식(«상수» · [단위] 로 시작)
  - 기호식의 «말로» 짝은 따로 세우지 않음 (중복 없음)
  - «＋ 공식으로 추가» 로 내 공식 저장 가능. 같은 한글 식을 쓴 다른 문제에도 자동으로 연결됨.
- 목록 공식의 말로 식과 한글 다른꼴로도 같은 식인지 판정함
- 공식 3개 추가 (접지·지락·절연)
  - BIL = 5E + 50 [kV] (비유효접지 · 20호 이상) / E = (BIL − 50)/5
  - 절연계급 E = Vn/1.1 ↔ 공칭전압 Vn = 1.1E
  - 정격전압 Vr = Vn × 1.2/1.1 (피뢰기 문제는 제외)
