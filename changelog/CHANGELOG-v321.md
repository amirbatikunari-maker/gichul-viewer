# v321 — 폰 «나눠 보기» 디버그

## 고친 것 (중요)
- **가만히 있어도 무한 반복하던 것** — 3초에 칸 높이 값을 724번 다시 씀
  - 원인: 이름표·높이 값을 «같은 값이어도» 다시 쓰면 «바뀌었다» 신호가 나고, 그 신호를 나눠 보기가 다시 받아 또 쓰던 것
  - 폰이 뜨거워지고 버벅이며, 손가락 스크롤이 가끔 칸 대신 페이지로 가던 원인
  - 이제 바뀔 때만 씀 → 가만히 있을 때 0번
- **가리는 막대 높이 재기가 1.5초마다 무겁게 돌던 것** → 화면 크기가 바뀔 때·켤 때만 (스타일 조회 3초 3,697번 → 130번)
- 공부 타이머 같은 칸과 무관한 화면 변화에는 반응 안 함
- **폰 가로(높이 낮음)에서 아래가 화면 밖으로 넘치던 것** — 최소 높이 340px 고정 → 200px
- **다른 기능이 문항을 다시 그리는 순간 한 프레임 풀려 보이던 것** → 그 자리에서 바로 다시 붙임
- 위 막대 재기에서 아직 «안 붙은» sticky 막대까지 빼서 칸이 작아지던 것 → 실제로 붙은 것만

## 추가
- **칸마다 읽던 위치 기억** — 동기화 등으로 화면이 다시 그려져도 답안·풀이 칸 스크롤이 맨 위로 튀지 않음 (다른 문항은 맨 위부터)
