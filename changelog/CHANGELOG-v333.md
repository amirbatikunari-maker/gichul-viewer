# v333 — «왜» 노란 상자에 첫 줄만 들어가던 것

## 원인
- v332 부터 «왜» 를 한 줄에 한 가지씩 줄바꿈해서 받음
- 그런데 화면 글 그리기(mdLite)는 «- 왜: …» 목록 칸 안의 줄바꿈을 몰라서 둘째 줄부터 새 문단으로 그림 → 노란 상자 밖으로 빠짐

## 고침
- 화면: «- 왜:» 다음 줄들은 빈 줄 · 새 목록 · 단계 머리 · 식 · 답 줄이 나오기 전까지 같은 상자 안에 줄바꿈으로
  - 이미 저장된 해설도 바로 고쳐짐 (다시 돌릴 필요 없음)
  - 두 칸 이상 들여 쓴 줄은 어느 목록 칸이든 그 칸 안으로
  - 보통 목록 뒤 문단은 예전처럼 따로 (안 섞임)
- 해설 틀(practice · review · explain-batch): «왜» 둘째 줄부터 들여 써서 저장
- «왜» 상자는 접지 않음 — 짧아졌으니 펼치기·접기 없이 다 보임 (검산·흔한 실수 등 긴 것은 예전처럼)
