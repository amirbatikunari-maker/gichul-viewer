## 고침 (워커 빌드 v329)
- 변환 과정·게이트 표를 **맨 바깥 logic 칸** 으로 옮김 — 소문항마다 한 묶음 { q, derive, gates }
- 어디에 적어 와도 모아서 인정: 바깥 logic · 바깥에 derive/gates 만 따로 · 예전처럼 단계 안(v327) · JSON 글자
- 빠진 칸 채우기(작은 틀)도 logic · 진리표를 채울 수 있게
- 진단 창에 «logic 몇 묶음 · 단계 안 · 바깥» 이 보이게 (다음에 또 미달이면 원인이 바로 보임)

## 화면
- 논리식 표가 그 소문항 풀이 **바로 밑** 에 붙음 — (2) NAND 변환·게이트 표는 (2) 단계 밑
- 번호가 없는 묶음은 풀이 끝 «식 바꾸기 · 게이트 연결» 아래
- 예전(v327) 모양으로 저장된 해설도 그대로 보임
