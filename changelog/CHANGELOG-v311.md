# v311 — 연동 창: 선택 연동이 건너뛰던 문제 · 동일/유사 표시

## 고침
- 「선택 N개 연동」에서 고른 문항에 다른 유형이 이미 붙어 있으면 **전부 말없이 건너뛰던 것** 고침
  - 이 문제만 혼자 그 유형이면 → "이 문제를 고른 쪽 유형(B)으로 옮겨 함께 묶을까요?" 먼저 물음
  - 아니면 → "고른 문항도 이 유형(A)으로 옮길까요?" 물음 (그 유형의 나머지 문항은 그대로)
  - 둘 다 취소하면 아무것도 안 바뀜
- 연동된 문항은 찾은 목록에서 빠지고 **아래 «유형» 문항 목록으로 내려감**
  - 방금 들어온 칩은 노란색으로 잠깐 반짝임
  - 찾은 목록 머리에 "연동된 N개는 아래 ↓" 표시

## 추가
- 아래 문항 목록 칩마다 이 문제와의 사이 표시
  - 동일(초록) = 대·중·소 모두 같음
  - 유사(파랑) = 대문항만 같음
  - 소 미정(노랑) = 대·중 같고 소문항이 비어 있음 → 소문항까지 넣으면 동일
  - 지금(보라) = 이 문제
- 목록 위에 동일·유사·소 미정 개수 한 줄
