# v284 — «체크한 것 빼기» → «맞힘 N번↑ 빼기» (회독 세기)

고친 파일: `practice.html` · `sw.js` · `index.html` (워커 재배포 없음)

- 맞음·틀림을 누를 때 «맞힌 횟수 · 틀린 횟수» 를 따로 셈 (prac:prog:v1 에 ok · no 칸)
  - 예전 기록은 마지막 결과를 1번으로 침 (마지막이 맞음이면 맞힘 1)
- 랜덤 겹치기 «체크한 것 빼기» → «맞힘 N번↑ 빼기» + [− N +]
  - N 번 이상 맞힌 문항만 뺌 — 틀린 것 · 아직 안 푼 것은 남음
  - N=1 → 1회독 (한 번 맞힌 것 소거) · 다 맞혔으면 + 로 2 → 2회독째 …
  - N 을 바꾸면 걸려 있는 랜덤을 바로 다시 뽑음
- 한눈에 «✓ 맞음» 단추 오른쪽 위에 맞힌 횟수 뱃지 (×2)
- 🗺 미니맵
  - 두 번 이상 맞힌 칸에 횟수 숫자
  - «맞힘 N번↑ 흐리게» 거르기 — 랜덤 N 과 같은 기준, 남은 것만 또렷
  - 아래 «지금 문항 맞힌 횟수 [− n +]» — 잘못 누른 것 바로잡기
  - 칸 위에 올리면 맞힘·틀림 횟수
