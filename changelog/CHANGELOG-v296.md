# v296 — 동일 = 대·중·소 모두 같게 · 유사 = 대문항만 같고 중문항은 문제 특성으로

고친 파일: `practice.html` · `sw.js` · `index.html` (워커·SQL 없음)

## 뜻 바꿈 (v292 → v296)
- 대문항 = 유사 묶음 · 중문항 = 문제 특성(무엇을 묻는가) · 소문항 = 동일 문제
- 동일 = 대·중·소 모두 같음 (회독·해설 같이) · 유사 = 대문항만 같음
- 번호 옆 표시도 이 기준 («같은 단원» 표시는 «유사» 로 합침)

## 분류판
- «＝ 이 문제와 동일로» : 고른 문항을 기준과 대·중·소 모두 같게
  - 기준에 빈 칸이 있으면 윗칸 이름을 그대로 씀 (대문항만 없을 때 물음) → 대·중·소가 같은 이름
- «≈ 이 문제와 유사로» : 대문항만 같게, 중문항은 문항마다 «특성» 이름을 추천 → 칸에서 고쳐 «적용»
  - 추천: 그 문항이 원래 쓰던 중문항 → 문제가 묻는 말 → 첫 물음의 앞말(«방폭형 전동기») → 추천어
  - «🤖 AI 추천» — 기준 문제와 무엇이 다른지를 이름으로, 고른 문항 전부 한 번에 (글만 · 싼 모델)
  - 기준과 같은 중문항을 쓰면 막음 (그럴 거면 «동일로»)
  - 소문항 = 그 중문항 이름 (그 문제만의 동일 묶음)
- 칸 이름: 대문항(유사 묶음) · 중문항(문제 특성) · 소문항(동일 문제)

## 중복 묶기
- «동일 −» = 대·중·소가 같은 것만 접기 · «유사 −» = 대문항이 같은 것까지 접기
- 켜진 단추를 다시 누르면 접기 끔
