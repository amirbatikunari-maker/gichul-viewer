# v371 · 단축키 새로 (예전 단축키는 모두 끔)

| 키 | 하는 일 |
|---|---|
| Esc | 열린 창(잘라 넣기·유형·미니맵·공식·고르기 창 등)이 있으면 그것만 닫음, 없으면 한눈에 나가기 |
| ← → | 앞 / 뒤 문항 |
| ↑ ↓ | 회독 +1 / −1 (넘어가지 않음) |
| O | 회독 +1 하고 다음 문항 (답안 줄 ＋와 같음) |
| X | 틀림 (기록하고 다음) |
| M | 미니맵 |
| N | 공식 |
| N 두 번 | 상세 Opus 해설 |
| S | 상세 Sonnet 해설 |
| Q / W / E | 연도 / 회차 / 번호 칸으로 들어감 (칸 안에 있어도 옮겨 감 · 주황 테두리 잠깐 표시) |
| R / T | 해설 글자 크게 / 작게 |
| F / G | 수식(라텍스) 크게 / 작게 |
| V / B | 줄간격 넓게 / 좁게 |
| V 두 번 | 이지뷰 ↔ 원래대로 |
| C 두 번 | 잘라 넣기 |
| L | 최신순 켜기 / 끄기 |
| K | 쉬운해설 고정 / 풀기 |
| P | 접기 / 펼치기 |

## 동작 규칙
- 칸·목록 안에서는 화살표가 그 칸 안에서만 움직임.
  - 연도·회차·번호 칸에서 ↑ ↓ 로 고르면 바로 그 문항으로 감. 칸에서 손을 떼지 않으므로 계속 ↑ ↓ 할 수 있음.
  - 번호 칸에서 ↑ ↓ 로 지나가다 «없음» 번호에 닿으면 건너뜀 (만들기 질문 안 뜸).
- 글 쓰는 칸(입력칸·글상자·AI 창 등)에서는 단축키가 동작하지 않음.
- Ctrl·Alt·⌘ 와 같이 누르면 단축키를 건드리지 않음.
- 한글 자판이어도 같은 자리 키로 동작함.
- V·N 은 두 번 누르기를 기다리느라 한 번 누를 때 0.3초 늦게 동작함.
- R T F G V B 와 화살표는 꾹 누르면 계속 바뀜.
