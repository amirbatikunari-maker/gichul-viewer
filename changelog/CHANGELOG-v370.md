# v370 · 있는 문항이 목록에 안 보이던 것 (18년 3회 14번)

- **원인**: 이 기기에 저장해 둔 목록(캐시)을 «문항 수가 같으면 그대로» 믿고 썼음.
  - 한 문항이 지워지고 다른 문항이 생기면 수는 같아서, 새 문항이 목록·레일·번호 칸 어디에도 안 보였음.
  - «↻ 새로 받기»를 누르면 그제야 나왔음.
- **이제**: 캐시로 화면을 먼저 그린 뒤, 뒤에서 조용히 서버의 «문항 id 목록»만 받아 맞춰 봄.
  - 다르면 빠진 문항만 받아 끼우고, 없어진 문항은 뺌.
  - 보던 문항·연도·회차 고른 것은 그대로 둠.
  - 실시간 기록에 «목록을 서버와 맞췄습니다 — 새로 생긴 문항 N개 · 없어진 문항 M개»가 남음.
- v369 «N번 — 없음 (＋ 만들기)»: 만들기 전에 서버에 정말 없는지 먼저 봄.
  - 있으면 새로 만들지 않고, 받아서 목록에 넣고 바로 엶 (같은 번호가 두 개 생기지 않게).
