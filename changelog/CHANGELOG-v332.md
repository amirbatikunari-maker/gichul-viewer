# v332 — Q&A 칸 다시 만듦 · «왜» 를 핵심·이유 위주로

## 1. 쉬운 풀이 아래 Q&A 칸이 안 펴지고 고치기·지우기 안 되던 것
- 원인: 항목 이름(.qai)이 AI 단추(ai-viewer.js 의 .qai = 30×30 단추)와 겹침 → 항목이 30px 칸에 찌그러져 글자가 왼쪽 밖으로 밀리고 눌러지지 않았음
- 이름을 qx- 로 바꾸고 모양 새로
  - 머리줄: 💬 Q&A · 개수 · 모두 펼치기/접기 · ＋ 추가(직접 적어 넣기)
  - 줄마다: ▶ · Q1 동그라미 · 질문 · 날짜 · ✎ 고치기 · 🗑 지우기 (마우스 올리면 진하게, 폰은 늘 보임)
  - 펼치면: Q · A 표시 + 답(표·수식 그대로)
  - 고치기·추가: 칸 안에서 바로 · Ctrl+Enter 저장 · Esc 취소
  - 밤 모드 색 맞춤
- AI 창에서 본문저장한 것은 펼친 채로 들어감

## 2. «왜» 해설 — 군더더기 빼고 이유만
- 핵심 2~5줄, 한 줄에 한 가지
  - ⓐ 이 식을 쓰는 근거
  - ⓑ 식에 붙은 것마다 왜 붙는지 (3 → 3상 · 2πf → 각주파수 · V/√3 → 선간을 대지전압으로 · 10⁻⁶ → μF를 F로)
  - ⓒ 표·○△− 분류는 «기준 → 그래서» 꼴 (예: 물기 있는 곳 → 젖은 몸은 저항이 확 떨어짐 → 전압 상관없이 ○)
  - ⓓ 답안지가 건너뛴 과정 (어느 값을 합쳤는지 · 환산 · 절사)
- 금지: 대입식 숫자를 글로 다시 읊기 · «해당 없음 / −로 표시» 처럼 결과만 되풀이 · 문제 다시 쓰기
- ans 를 «answer란 표 참고» 로 비우지 않음
- 글 칸에서 «백슬래시·$ 금지» 옛 규칙 삭제 — 프롬프트·check·trap 설명 모두 (v330 의 «짧은 식은 $…$» 와 부딪혔음)
- 이미 만든 해설은 그대로 — 상세 Opus/Sonnet 다시 돌리면 새 규칙으로
