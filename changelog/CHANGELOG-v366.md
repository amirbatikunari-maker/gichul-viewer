# v366 · 그림 잘라 넣기 — 통째 교체 · 어디에 넣는지 분명하게

## 그림 통째 교체
- 위쪽 «자를 그림» 줄에 **📋 붙여넣어 통째 교체** / **📁 파일로 통째 교체** 단추를 둠.
  - 그림이 위쪽 자리에 들어가고, «↩ 원래 그림»으로 되돌릴 수 있음.
  - 선을 안 그으면 칸 하나 = 지금 고른 «문제»나 «답» 그림을 통째로 바꿈 → «잘라서 넣기»로 저장.
  - 선을 그어 여러 칸으로 나눠 넣어도 됨.
- 그림이 없거나 «통째 교체»를 누른 뒤 Ctrl+V 하면 위쪽 그림을 바꿈.
- 칸을 누른 뒤 Ctrl+V 하면 예전처럼 그 칸에 «빠진 부분 붙이기».

## 칸마다 어디에 어떻게 들어가는지
- 숨은 선택 칸 대신 단추로 고름.
  - [☑ 이 칸 넣기 / ☐ 안 씀] [번호]
  - [문제 그림 바꾸기 | 문제 아래에 잇기 | 답 그림 바꾸기 | 답 아래에 잇기]
- 칸마다 결과를 한 줄로 늘 보여 줌.
  - 초록: «→ 8번 «문제» 그림을 이 칸으로 바꿈 (지금 그림은 덮어씀)»
  - 보라: «↳ 8번 «답» 그림의 지금 그림 아래에 이어붙임» / «↳ 위 칸 아래로 이어붙여 한 장으로»
  - 회색: «이 칸은 저장하지 않음»
  - 붙인 그림이 있으면 «(+ 붙인 그림)»이 같이 표시됨.
- 선을 안 그었으면(칸 하나) 기본값은 지금 고른 그림 칸(문제/답)을 바꾸는 것.
- 붙인 그림 위치도 단추로 고름: [⬆ 칸 위에 붙이기 | ⬇ 칸 아래에 붙이기]
