# v327 — 해설이 과정을 건너뛰지 않게 (논리식 · 식풀이 · 전 유형)

## 증상
- 논리식(Y = A + B·C바 → NAND·NOR 만으로) 해설이 드모르간 변환 과정을 통째로 빼고 «= 최종식» 만 적음
- 회로 소문항은 «답안지 그림처럼 만듦» 한 줄로 끝 — 무엇을 어디에 잇는지 없음
- 계산도 숫자대입식이 결과만 · «왜» 가 한 줄 · «위와 같이» 로 넘어가는 곳

## 워커 (빌드 v327) — 해설 규칙
- **논리식·논리회로**
  - 식 바꾸는 과정(derive): **한 줄에 법칙 하나** — 원래 식 → 이중부정 → 드모르간 → NAND/NOR 로 읽기 → NOT 을 NAND(X,X) 로 … 한 등호에서 두 가지를 한꺼번에 바꾸지 않음
  - 게이트 연결표(gates): 게이트마다 종류 · 입력 · 출력식 · 하는 일 — 이 표만 보고 답안 그림을 따라 그릴 수 있게
  - 진리표(truth): 입력 조합 전부(3입력 8줄) · 원래 식과 NAND 회로 · NOR 회로 출력을 나란히
  - 글 칸에서는 부정을 «C바» 처럼 글로 (수식이 깨져 보이던 것)
- **전 유형 공통 — 대충 넘기기 금지**
  - «답안지 그림처럼 · 그림과 같이 · 위와 같이 · 같은 방법으로 · 마찬가지로 · 생략 · 이하 동일» 금지 → 실제 과정으로
  - 앞 소문항과 같은 방식이어도 이 소문항 값으로 다시 전부
  - 숫자대입식은 «대입한 모습 = 중간 계산 = 결과» (등호 두 번 이상)
- **검사** (어기면 다시 받음 / 채움)
  - 논리식인데 변환 과정 없음 · NAND/NOR 인데 게이트 표 없음 → 필수(다시 받음)
  - 진리표 없음 · 변환 줄에 법칙 빠짐 · 대충 넘기는 말 · «왜» 가 한 줄인 단계가 절반 이상 · 숫자대입식 결과만 → 보충(한 번 더 채움)
  - 논리식 문제는 «[동작설명] 한 줄씩» 검사에서 뺌 (식 하나뿐이라 헛돌던 것)
