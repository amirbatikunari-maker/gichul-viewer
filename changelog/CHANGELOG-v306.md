# v306 — «맞음» 단추를 «회독» 단추로 · 예전 맞음 표시는 저절로 회독 +1

고친 파일: `practice.html` · `sw.js` · `index.html` (워커·SQL 없음)

- v304 는 요청을 잘못 알아들어 «맞음 단추는 그대로 + 미니맵에 한 번 누르는 옮김 단추» 로 만들었음 → 바로잡음
- 단추: ✓ 맞음 → «＋ 회독» (한눈에 머리줄 · 일반 보기 머리 · 카드) · 옆 ✕ 틀림
  - ＋ 회독 = 회독 +1 (안 틀린 풀이로 셈 → «맞힘 −» 거르기도 그대로 씀) 하고 다음 문항
- 예전에 «맞음» 으로 표시된 기록 → 과목을 열 때 저절로 회독 +1 (알림 «예전 «맞음» N문항을 회독 +1 로 옮겼습니다»)
  - 같은 문제 묶음은 한 번 · 한 번 옮긴 기록은 표시가 남아 다시 안 올림 (기기 동기화로 다른 기기도)
  - 서버 기록을 한 번 받아 합친 뒤에만 옮김 → 다른 기기에서 이미 옮긴 것을 또 올리지 않음
  - 2026-09-27 00:30 이전 기록만 — 옛 판 앱이 켜진 기기에서 나중에 누른 것은 옮기지 않음
  - 새로 누르는 기록은 옮김 대상이 아님
