# v375 · «썩» 표시 — 버려도 되는 문제

- 문항 줄(한눈에 위쪽 줄 · 일반 보기 줄) 칸 **왼쪽 위에 작은 네모 «썩»**.
- 위치: 회독 숫자 뱃지(오른쪽 위)·🔒(왼쪽 아래)와 안 겹치게 왼쪽 위.
- 썩 = **한 번만 나온 유형(똥)** 이면서 **풀기 어려운 문제**만.
  - 똥이어도 풀이가 짧거나 서술형이면 표시 안 함 (쉬운 건 가져감).
  - 어려움: 답안의 «=» 개수가 과목 안에서 위쪽 40% · 4개 이상 (답안 글이 없으면 쉬운 풀이로) · 또는 내가 2번 이상 틀림.
- **Alt+클릭** 으로 손으로 바꾸기: 자동 → 썩 → 합 → 자동. 손으로 정한 썩은 진한 빨강 네모. 이 기기에만 저장.
- 답안 속 그림 주소(?a=b)·HTML 속성의 «=» 는 세지 않음. 답안·해설을 고치면 다시 셈.
- 처음/끝 칸에는 안 붙음. Alt+클릭은 칸 이동 없이 표시만 바꿈.
