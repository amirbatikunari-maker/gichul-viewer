# v223 — 연도 칸이 2021년에서 끊기던 것

## 증상

검수 화면 **연도** 칸에 **2026 · 2025 · 2024 · 2023 · 2022 · 2021** 여섯 개만 뜨고,
**2020년 이하가 통째로 사라졌음.** 자료는 멀쩡히 있는데 고를 수가 없었음.

## 원인 — Supabase 는 한 번에 1000줄만 준다

회차 목록을 만드는 코드가 이랬음.

```js
const { data } = await sb.from("practicals").select("year,session")
  .eq("subject_id", sid).order("year", {ascending:false}) …   // ← 끝까지 안 받음
```

지금 **1748문항**인데 1000줄에서 잘림. 그런데 정렬이 **연도 내림차순**이라
앞쪽 1000줄이 이렇게 채워졌음.

| 순서 | 무엇 | 누적 |
|---|---|---|
| 1 | 9523·94xx·9302·9301 (문제집 715문항) | 715 |
| 2 | 2026년 (39) | 754 |
| 3 | 2025년 (57) | 811 |
| 4 | 2024년 (54) | 865 |
| 5 | 2023년 (54) | 919 |
| 6 | 2022년 (54) | 973 |
| 7 | 2021년 제3회 (17) | 990 |
| 8 | 2021년 제2회 → **1008 · 여기서 잘림** | — |

**가짜 연도 715문항이 앞자리를 다 차지해서** 진짜 기출 뒤쪽이 밀려났던 것.
문제집 자료가 늘어난 뒤에 생긴 증상임.

## 고친 것

끝까지 나눠 받음.

```js
for(let from = 0; from < 40000; from += 1000){
  const r = await sb.from("practicals").select("year,session")… .range(from, from + 999);
  data.push(...(r.data || []));
  if(!r.data || r.data.length < 1000) break;
}
```

이제 **2026년부터 2008년까지 다 뜸.**

## 같은 함정이 또 있나 확인함

| 자리 | 상태 |
|---|---|
| `fetchAll` (모아보기·중복찾기) | 이미 나눠 받고 있었음 ✅ |
| `practice.html` 실기 목록 | 이미 나눠 받고 있었음 ✅ |
| `explain-batch.html` 대상 고르기 | 이미 나눠 받고 있었음 ✅ |
| `storage-clean.html` 참조 모으기 | 이미 나눠 받고 있었음 ✅ |
| **`loadSheets` (연도·회차 칸)** | **여기만 빠져 있었음** ← 고침 |

`load()`(회차 하나 불러오기)는 최대 30줄이라 나눠 받을 필요 없음.
