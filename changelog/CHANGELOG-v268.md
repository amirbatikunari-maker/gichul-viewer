## 1. 한눈에 머리줄 ✂ 옆 «🏷 유형»

유형이 없으면 `🏷 유형`, 있으면 `🏷 주상변압기 탭 조정 ②`(같은 유형 문항 수). 누르면 쪽지가 뜬다.

| 칸 | 하는 일 |
|---|---|
| 추천 | 보라 = 이미 있는 유형(누르면 바로 넣음) · 흰색 = 새 이름(누르면 입력칸에 채움 → 고쳐서 Enter) |
| 🤖 AI 추천 | 누를 때만. 글만 보냄(그림 X) · Haiku · 약 1~2원. 결과는 기기에 남겨 그 문항은 다시 안 부름 |
| 유형 목록 | 체크하면 이 문제가 그 유형으로. 입력칸은 찾기 겸 새로 만들기(Enter) |
| 번호로 연동 | `12-1 6` · `2012 1 6` · `2012년 1회 6번` · 같은 회차면 `6`. 넣는 대로 «→ 2012년 1회 6번 · 유형 없음» 미리보기 |
| 닮은 문항 | 글이 닮은 문항(연관 0.35↑) 다섯 — «연동» 한 번이면 같은 유형 |
| 이 유형 문항 | 눌러서 이동 · ✕ 로 이 유형에서 빼기 |
| 머리 | ✎ 이름 바꾸기(같은 이름이 있으면 합칠지 물음) · 빼기 |

- 쪽지를 연 채 레일로 다른 문항에 가면 쪽지도 그 문항으로 따라감 — 연달아 붙이기 좋게
- Esc · 바깥 누르기로 닫힘 (Esc 가 한눈에까지 닫지 않음)

### 연동 규칙 — «유형을 정하는 것» 과 «번호로 잇는 것» 은 같은 일

| 이 문제 | 그 번호 | 결과 |
|---|---|---|
| 유형 A | 없음 | 그 번호 → A |
| 없음 | 유형 B | 이 문제 → B |
| 없음 | 없음 | 이름을 물어(추천 이름을 미리 채움) 둘 다에 |
| A | B (다름) | ① B 전체를 A 로 합칠까 → 아니면 ② 그 한 문항만 A 로 옮길까 |

### 추천은 어떻게 (네트워크 0)

1. 닮은 문항이 이미 가진 유형 — «15-2 3번과 82% 닮음»
2. 문제 글에 이름 낱말이 거의 다 들어 있는 유형
3. 새 이름 후보 — 문제가 «무엇을» 묻는지 뽑음:
   «… 고압측의 사용탭은 얼마로 …» → `고압측 사용탭 계산` · «… 콘덴서의 용량은 몇 …» → `전력용 콘덴서 용량 계산`
4. 출제기준 세부항목 · 주요항목

## 2. 중복 묶기 = 같은 유형

- 수준 고르기에 **«수동 — 내가 «유형» 으로 묶은 것만»** 을 더하고 기본으로 (한 번만 바꿔 둠, 다시 고르면 그대로 기억)
- 엄격·보통·느슨은 남김 — 고르면 «유형 + 자동». 한 문항이 둘 다 걸리면 유형 쪽이 이김
- 수동일 때는 글자 견주기(5-gram)를 아예 안 돌림 — 계산도 아낌
- 유형을 바꾸면 글자 견주기는 다시 안 돌리고 묶음만 다시 짬 (`__pracDupRecompose`)
- 목록 카드 뱃지: 손으로 묶은 것은 `중복 N문항` 대신 `🏷 유형이름 N`
- **출제 이력도 같이 합쳐짐** — 같은 유형의 «출제 84.91.96…» 연도를 합집합으로 → 누적 N회 · 확률 · 금은동이 유형 단위로
  - 예전 자동 묶음으로 합쳐지던 이력은, 수동 모드에선 유형을 붙인 만큼만 합쳐짐 (닮은꼴 연도는 전처럼 따로 더해짐)

## 3. 레일 번호 옆 ▼

- 중복 묶기가 켜져 있을 때, 묶인 덩어리의 대표 번호 오른쪽에 ▼ 꼬리
- 누르면 묶인 문항이 차례로 내려옴(유형 이름 · 대표 · 해설 있음 점) → 눌러서 그 문항으로
- 한눈에 레일 · 일반 보기 레일 둘 다. 회차를 하나 골라 보는 중엔 묶기가 꺼지므로 ▼ 도 없음
