# v355 — 필기 요금 어림 바로잡기 · 필기에선 글자 변환 안 함 · 2026년 3회 쉬운해설 80문항

## 1. «해설 돌리기» 요금 어림 — Sonnet 이 Opus 보다 비싸게 나오던 것
- 어림값은 «지난 3번 이상 실제로 쓴 돈의 평균» 인데, 필기 화면도 «실기» 기록(긴 틀·다시 받기)을 쓰고 있었음
  - Sonnet 은 실기 기록이 쌓여 문항당 ~131원, Opus 는 기록이 없어 기본값 80원 → 거꾸로 보임
- 필기·실기 요금 기록을 따로 둠 · 기본값: 필기 Sonnet ~30원 / Opus ~75원 · 실기 Sonnet ~130원 / Opus ~330원
- 단추에 적힌 «~N원» 도 실제 어림값으로 표시

## 2. 필기 화면에선 «글자 변환» 을 할 일로 안 침
- 해설은 문제·답안 «그림» 을 그대로 보고 쓰므로 글자 변환이 필요 없음 (필기 문제집은 글자도 이미 들어 있음)
- «한 번에(변환+해설)» · «빠르게» 같은 일괄 작업이 필기에선 해설만 돌림 · 손으로 «변환» 을 누르면 그건 돎
