# v288 — 회독·맞음을 «같은 문제» 끼리 확실히 연동 · 표시 한 가지로 · 일반 보기도 한눈에와 같게

고친 파일: `practice.html` · `sw.js` · `index.html` (워커·SQL 추가 없음 — v287 supabase-study.sql 은 그대로 필요)

## 연동
- 같은 문제 = 소문항 이름이 같음 · 글 90% 이상 같음 · 책이 적은 출제 연도 목록이 같음
- 맞음 · 틀림 · 회독 −/+ · 맞힘 −/+ 를 누르면 같은 문제 «모두» 에 같은 기록을 적음
  (전에 서로 달랐으면 큰 값으로 먼저 합침) → 기기 동기화도 묶음 모두
- 「회독 범위」 고르기는 뺌 — 기록 자체를 함께 적으므로 셈이 하나뿐
- 비슷한 유형(대·중문항만 같음)은 연동 안 함 → 따로 풀어야 함
- 답안 회독 칸 앞 «🔗N» = 같이 기록되는 같은 문제 수 (올리면 목록)

## 표시 하나로
- 모든 곳이 같은 기록을 읽음: 레일 · 카드 · ✓맞음 뱃지 · 답안 회독 · 미니맵 · 랜덤 거르기
- «오답만» · «북마크+오답» · 세션 숫자가 예전 세션 기록(기기 한정·연동 없음)을 보던 것 → 진도 기록으로
- 레일 번호 색 = 미니맵 색 (맞음 초록 · 틀림 빨강 · 푼 기록만 파랑) · 2회독 이상이면 번호 위 숫자
- 카드 «N회 풂» → «N회독 · ✓맞힘»

## 일반 보기 = 한눈에
- 문제 칸 «✎ 고치기» 옆 🗺 미니맵 (지금 문항 테두리 · 칸 누르면 그 문항으로 · 목록에 없으면 한눈에로)
- 답안 칸 «✎ 고치기» 옆 [🔗N − N회독 · ✓n +]
- 머리 «✓ 맞음» 에도 «N회·✓n» 뱃지
