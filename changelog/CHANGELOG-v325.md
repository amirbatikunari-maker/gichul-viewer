# v325 — 고정 문항: 상세 단추는 됨 · 해설 돌리기는 안 됨

## 바뀐 규칙
- 🔒 쉬운해설 고정 문항도 **카드·한눈에의 «✎ 상세 Opus / 상세 Sonnet» 단추(직접 누름)** 로는 다시 쓸 수 있음
  - 누르면 «고정 문항입니다 — 이 단추로만 다시 씀, 고정은 유지» 확인창 → 확인하면 뽑아서 저장
  - 다시 써도 **고정은 그대로** 유지
- **«✎ 해설 돌리기»(여러 문항)** 는 고정 문항을 절대 안 돌림
  - «이미 해설 있는 것도 다시 쓰기» 를 켜도 · 이 문제 / 이 회차 / 고른 번호 / 목록 전체 어느 범위든
  - **«↻ 실패한 것 다시»** 에서도 뺌 (예전엔 실패 목록을 그대로 다시 돌려 이 확인을 안 거쳤음 — 뽑기 직전에 한 번 더 막혀 «실패» 로만 셌음)
- 자동 생성 · 다시 해석 · 꾸미기 · 자동 해설 진행은 예전처럼 고정 문항을 뺌
- 🔓 고정 단추 설명 문구도 바뀐 규칙으로

## 확인
- 고정 문항에서 상세 Sonnet → 확인창 → 워커 호출 → 새 해설 저장 → 고정 유지 · 취소하면 안 뽑음
- 해설 돌리기(이 회차 · 다시 쓰기 켬) → «2문항 · 🔒 고정 1개 건너뜀» · 실제로 1·3번만 돌림
- 이 문제(고정) → 시작 단추 꺼짐
