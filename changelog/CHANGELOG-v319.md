# v319 — Ctrl + / 로 AI 창 열기·닫기

## 추가
- **Ctrl + /** (맥 ⌘ + /) → AI에게 묻기 창 열기 · 한 번 더 누르면 닫기
  - 열면 바로 입력칸에 커서 → 곧장 질문 입력
  - AI 입력칸에서 치는 중이어도 동작 (닫기)
  - 한글 자판 상태여도 같은 자리 키면 동작
  - `/` 만 누르면 반응 안 함
- 실기(practice) · 필기(index) 둘 다
- 단축키 도움말(⌨ 단축키)에 한 줄 추가
