# v286 — 회독은 «진짜 같은 문제» 끼리만 같이 셈 (비슷한 유형은 따로)

고친 파일: `practice.html` · `sw.js` · `index.html` (워커 재배포 없음)

- 랜덤 줄 «회독 범위» 고르기 (기본: 같은 문제만)
  - 같은 문제만 : 소문항 이름이 같음 · 글이 90% 이상 같음 · 책이 적은 출제 연도 목록이 같음
  - 중문항까지 / 대문항까지 : 비슷한 유형까지 한 번에 셈
  - 문항 하나만 : 예전 v285 방식
- «체크 N번↑ 빼기» · «맞힘 N번↑ 빼기» 가 이 범위로 셈
  - 묶음 안에서 가장 많이 푼 횟수를 묶음 전체 횟수로 봄 (저장된 기록은 안 바꿈)
  - 예) 24-3 17 을 풀면 소문항이 같은 12-1 6 도 1회독 → 안 나옴
        대문항만 같은(비슷한) 문제는 그대로 남아서 다음 뽑기에 나옴
- 빈출·금·은 «같은 유형은 하나만» 은 예전처럼 대문항 기준 (한 번 뽑을 때 비슷한 것 중복 방지)
