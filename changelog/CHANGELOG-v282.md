# v282 — 유형 쪽지에서 본문으로 찾아 연동 · 제자리 미리보기

고친 파일: `practice.html` · `sw.js` · `index.html` (워커 재배포 없음)

- «번호로 연동» 칸 → «번호·본문으로 연동»
  - 숫자만 치면 예전처럼 번호(12-1 6 · 같은 회차면 6)
  - 글자가 섞이면 이 과목 전체 본문에서 찾음 — 문제 › 답안 › 유형 이름 › 쉬운 풀이 순
  - 띄어 쓴 낱말은 모두 든 것만 · 띄어쓰기 무시(영상 변류기 = 영상변류기)
  - 결과마다 찾은 자리 한 토막(노란 표시) · 어디서 찾았는지(문제/답안/유형/풀이) 표시
  - 위 8개, «더 보기» 로 40개까지
- 👁 (또는 번호 글자) 누르면 화면 이동 없이 쪽지 안에서 문제 그림·답 펼침 → 바로 «연동»
  - 그림 누르면 새 창에서 크게 · «↗ 이 문항으로 이동» 은 따로 둠
- 글자로 찾을 때 Enter = 맨 위 결과 미리보기 (실수로 묶이지 않게 연동은 단추로만)
- «닮은 문항» 도 같은 방식 — 이름 눌러도 이동하지 않고 미리보기
- 이미 같은 유형인 결과는 «같음» 으로 흐리게
- 폰에서 칸이 숫자 자판으로 뜨던 것 → 글자 자판(한글 입력 위해)
