# v361 · 한눈에 머리줄 정리 — 맨 위에는 «닫기»만

- **문제 줄**: [− 75% ＋][🏷 유형] ───── [◧ 이지뷰][이지뷰|원래대로][✂ 잘라 넣기][🗺 미니맵][📐 공식]
- **답안 줄**: [✕ 틀림][− n회독 ＋][✎ 고치기]
- **쉬운 풀이 줄**: [해설 AUTO][✎ 해설 돌리기][− 가 9pt ＋][− √100% ＋][＋ 줄간격 −][접기] …
- 맨 위에서 없앤 것:
  - ＋ 회독 · ✕ 틀림 → 회독은 답안 줄 ＋로, 틀림은 답안 줄 단추로 옮김
  - 글자 크기 · 수식 크기 · 이지뷰 · 잘라 넣기 · 유형 · 해설 돌리기 · 머리줄의 상세해설
- 문항을 넘겨 칸이 새로 그려져도 단추는 제자리로 다시 붙음.
- 단추가 한 줄에 다 안 들어가면 줄이 바뀜 (줄어들어 사라지지 않게).
- 새 파일: `practice/p71.js` (practice.html 맨 끝에 script 추가됨)
