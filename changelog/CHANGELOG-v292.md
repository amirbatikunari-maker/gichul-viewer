# v292 — 🗂 유형 분류판 · 동일/유사 구분 · 중복 묶기 «동일 −» «유사 −»

고친 파일: `practice.html` · `sw.js` · `index.html` (워커·SQL 없음 — 대·중·소 칸은 v273 supabase-qtype.sql)

## 뜻을 하나로
- 대문항 = 단원 · 중문항 = 유사 문제(값·조건만 다른 같은 갈래) · 소문항 = 동일 문제(회차만 다른 같은 문제, 회독도 같이 셈)

## 🗂 유형 분류판 (쪽지 머리 «🗂 분류판» · 일반 보기 등급 줄 끝 «🗂 분류판»)
- 왼쪽 세 칸: 대문항 → 고른 대문항 «안의» 중문항 → 고른 중문항 «안의» 소문항 (칸마다 찾기·새 이름 Enter · ∅ 없음)
- 오른쪽: 고른 칸의 문항 — 위 찾기 칸에 본문 낱말(방폭 구조)·번호(12-1 6)를 치면 찾은 문항
  - ☑ 여러 개 · 👁 제자리 미리보기(그림·답) · 번호 옆 «동일»(초록) «유사»(파랑) «같은 단원» = 기준 문항과의 사이
- 아래 «☑ N개 동일 문제로 / 유사 문제로 / 대문항에 넣기» — 고른 칸(대 › 중 › 소) 그대로 한 번에
  - 대문항이 바뀌는 문항은 원래 중·소문항을 비움 · 중문항이 바뀌면 소문항을 비움 · «빼기»
- 위 «＝ 이 문제와 동일로» «≈ 이 문제와 유사로» — 분류판을 연 문항 기준
  - 동일 = 대·중·소 모두 같게 · 유사 = 대·중만 같게, 소문항은 따로
  - 기준 문항에 칸이 비어 있으면 그때 이름을 물음

## 🏷 쪽지
- 중·소문항 목록은 윗단계 «안의» 이름만 (▾ 다른 것도 보기) · 윗단계가 비어 있으면 먼저 정하라고 알림
- 찾은 목록 ☑ 체크박스 · «전체 고르기» · «선택 N개 연동» · 번호 옆 동일/유사 표시

## 중복 묶기
- «⧉ 중복 묶기 (유형 40)» → «⧉ 중복 묶기» (접힌 수는 올리면 보임)
- 빠른 단추 «동일 −» (소문항이 같은 것만 접기) · «유사 −» (중문항이 같은 것까지 접기) — 다시 누르면 «대문항 −»
- 고르기 칸에도 같은 셋 + 자동(엄격·보통·느슨)
- 랜덤 «같은 유형은 하나만» · 등급 유형 수도 고른 묶기 기준을 따름
