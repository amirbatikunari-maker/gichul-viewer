# v293 — 동일 문제는 해설도 연동

고친 파일: `practice.html` · `sw.js` · `index.html` (워커·SQL 없음)

- 동일 문제 = 대 › 중 › 소문항이 모두 같은 문항 (분류판·쪽지로 사람이 정한 것만 — 글 닮음 자동 추정은 안 씀)
- 한 문항의 해설이 바뀌면(AI 뽑기 · 상세 Opus/Sonnet · 고치기 · 두문자 저장 무엇이든) 같은 동일 문제에도 같은 해설을 적음
- 동일 문제로 묶였는데 해설이 없는 문항은 있는 쪽 해설로 채움 (여럿이면 🔒 고정한 것 → 긴 것)
  → «해설 없는 문항 뽑기» 에서 빠지므로 같은 문제를 두 번 뽑는 돈이 안 듦
- 🔒 고정한 문항은 덮어쓰지 않음 (그 문항의 해설은 다른 문항으로는 퍼짐)
- 유사 문제(중문항만 같음)는 해설을 연동하지 않음
- 쉬운 풀이 이름줄 «🔗 동일 N · 해설 연동» (올리면 묶인 번호)
  - 이미 서로 다른 해설을 가진 동일 문제면 «해설 K가지 → 이걸로 맞추기» — 누르면 지금 보는 해설로 모두 맞춤 (말없이 덮지 않음)
