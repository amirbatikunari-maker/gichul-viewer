# v346 — AI 창 뒤 반투명 없앰 · Q&A(본문저장) 칸이 글자만큼 늘어나게

## 고침
- **AI 창(AI에게 묻기)을 열면 뒤 화면이 어둡고 흐려지던 것** → 이제 뒤 화면 그대로.
  문제·답안을 보면서 스크롤·필기·버튼 누르기 가능. 닫기는 ✕ 또는 Esc (창 밖을 눌러도 안 닫힘).
  폰(폭 560px 이하, 아래에서 올라오는 창)은 옅게만 어둡게 · 밖을 누르면 닫힘 그대로.
- **한눈에 쉬운 풀이 아래 Q&A 칸이 찌그러져 글이 잘리던 것** → 글자만큼 늘어남.
  원인: 쉬운 풀이 칸이 세로 flex 인데 Q&A 상자(overflow:hidden)·쉬운 풀이 상자가 칸 높이에 맞춰 줄어듦.
  이제 줄어들지 않고, 길면 칸 전체가 한 번에 스크롤 (쉬운 풀이 상자 안에 따로 생기던 작은 스크롤도 같이 사라짐).
