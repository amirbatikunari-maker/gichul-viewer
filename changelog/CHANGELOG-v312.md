# v312 — 랜덤 줄에 「📅 최신순」

## 추가
- 랜덤 줄 `빈출 · 금 · 은 · 전체` 옆에 **📅 최신순**
  - 섞지 않고 최신 회차부터 차례로: 연도↓ → 회차↓ → 번호↑ (26년 2회 1번 → 2번 … → 26년 1회 …)
  - 개수 제한(20문항 등) 없이 조건에 맞는 전부
  - 문제집 자료(오고초려·핵심빈출·단답 등 가짜 연도)는 맨 뒤
  - 오른쪽 겹치기 그대로 걸림: 회차外 − · 체크 − N · 맞힘 − N → 걸린 문항은 빠지고 순서는 유지
  - 확률순은 최신순에서는 무시
  - 다시 누르면 새로 정렬(기록이 바뀐 것 반영) · ✕ 해제로 원래 목록
- 목록 정렬 속도 개선 (2000문항 전부 넘겨도 느려지지 않게)
