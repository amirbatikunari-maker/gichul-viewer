# v348 — 📐 공식 창 보강

## 바뀐 것
- 공식마다 **말로 식** 추가 (예: ε = (공칭 변류비 − 실측 변류비)/실측 변류비 × 100)
- 공식마다 **부호표** 추가: 기호 · 읽기 · 뜻 · 단위
- 공식마다 **출제율** 표시: 전체 문항 중 %, 출제 회차 수, 최근 5년 출제 수, 마지막 출제 연도
  - 공식별 탭에서 «출제율순» 정렬 가능
- 해설에 실제 식이 있으면 «이 문제 해설에 나온 식» 박스에 표시
  - «＋ 공식으로 추가»: 이름 입력 후 내 공식으로 저장함. 말로 식과 부호는 해설에서 자동으로 채움. 같은 식이 나오는 다른 문제에도 자동으로 연결함.
  - «이 문제에 연결»: 이미 있는 공식에 이 식을 붙임
- 문제와 공식 연결을 직접 고칠 수 있음: «이 문제에서 빼기», 공식 골라서 연결, 내가 추가한 공식 🗑 지우기
- 상단 바를 드롭다운으로 바꿈 (앱 헤더처럼)
  - 이 문제: 연도 / 회차 / 번호 선택, ↗ 열기, 📌 따라가기
  - 공식별: 단원 선택, 정렬, 검색
  - 번호별: 연도 / 회차 선택, 검색
- 폰에서 select 너비가 꽉 차던 문제를 고침, 부호표를 촘촘하게 줄임

## 동기화 (선택)
- 내가 추가하거나 연결한 공식은 기본적으로 이 기기(localStorage)에만 저장됨
- 여러 기기에서 같이 쓰려면 Supabase SQL Editor에서 `supabase-fx.sql`을 한 번 실행해야 함 (`practical_subjects.fx` 컬럼 추가)
- 실행하기 전에는 «서버 저장 안 됨» 토스트가 한 번 뜨고, 로컬 저장으로 동작함
