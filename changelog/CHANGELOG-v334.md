# v334 — «왜» 상자 들여쓰기

- 둘째 줄부터가 «왜:» 표 아래(왼쪽 끝)에서 시작하던 것 → 첫 줄 글 시작점에 맞춰 들여쓰기
  - 상자 안: «왜:» 표 | 글 두 칸으로 나눠 그림 (글 칸 안에서 줄이 바뀜)
  - 상자가 끝나면 다음 글은 원래 왼쪽으로 (들여쓰기 안 끌려감)
- 둘째 줄 앞에 빈칸 두 개가 붙어 몇 px 더 밀려 보이던 것
  - 원인: 줄 앞 빈칸 살리기(v153)가 들여쓰기 빈칸을 특수 글자로 바꿔 둠 → 이어지는 줄을 붙일 때 떼어 냄
