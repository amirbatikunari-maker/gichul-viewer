# v307 — AI 에게 묻는 중 ← → 가 뒤의 문제를 넘기던 것

고친 파일: `practice.html` · `sw.js` · `index.html`

- 한눈에의 ← → · Esc 단축키만 «글자를 치는 중인지» 를 안 보고 있었음
  → AI 입력칸에서 커서를 ← → 로 옮기면 뒤에 흐리게 보이는 문제가 이전/다음으로 넘어가고, Esc 면 한눈에가 닫혔음
- 입력칸 · 글 편집(contenteditable) · AI 창 · 유형 쪽지 · 분류판 · 두문자 창 · 미니맵 · 고치기 창 안이면 단축키를 쓰지 않음
  (한글 조합 중일 때도) — 한 문항씩 보기의 ← → · t(글자↔그림) · f(한눈에) 도 같은 기준
- 확인: AI 입력칸에서 ← ← Esc → 커서만 움직이고 문제 그대로·한눈에 안 닫힘 · 입력칸 밖 → 는 다음 문제
