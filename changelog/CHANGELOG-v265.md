# v265 — 해설 글이 한 덩어리로 흐르던 것 (문장 끝·긴 줄 자동 줄 나눔)

고친 파일: `practice.html` · `index.html` · `sw.js`(판번호만).
워커(`gichul-ai-worker`)·Supabase 는 안 건드림 — **재배포 필요 없음**.

---

## 1. 무슨 일이었나

- «쉬운 풀이» 의 글 칸(`왜` · `검산` · `외우기` · `흔한 실수` · `먼저 알아야 할 것`)은
  워커에서 **문자열 한 덩어리**로 옴.
- `solToMd()` 는 그 문자열을 그대로 한 줄에 실음 → 화면 너비에 맞춰 저절로 접힐 뿐,
  문장이 어디서 끝나는지 눈으로 안 잡힘.
- 모델(sonnet · opus)에게 «짧게 써라» 라고 시켜도 지키는 정도가 들쭉날쭉 →
  **모델에 기대지 않고 그려낼 때 나누는 쪽**으로 잡음.

## 2. 어떻게 고쳤나

- `practice.html` · `index.html` 맨 끝에 조각 하나 추가 — 렌더러(`mdLite` · `md`)를
  한 겹 더 감쌈.
- **그려내기 직전에만** 나눔. 저장된 `easy_md` 는 안 건드림 →
  «✎ 고치기» 창에는 원래 글이 그대로 뜸.
- 이미 저장해 둔 **옛 해설도 다시 만들 필요 없이** 바로 나뉘어 보임.

### 나누는 자리

| 구분 | 기준 |
|---|---|
| ① 문장 끝 | 마침표 · 물음표 · 느낌표 뒤. **앞 글자가 숫자면 제외** — `2.7` · `KEC 241.17` 은 안 나눔 |
| ② 긴 조각 | 한 조각이 `MAX`(기본 58자)를 넘으면 쉼표 · 가운뎃점 · 쌍반점 자리에서 한 번 더 |

### 안 건드리는 줄

- 소제목(`**…**`) · 머리글(`#`) · 표(`|`) · 수식만 있는 줄(`$$`) · 코드칸(```` ``` ````) ·
  상자표시(`[[box]]`) · 주석(`<!--cols:-->`)
- `MIN`(기본 34자)보다 짧은 줄, 이미 `<br>` 이 들어 있는 줄
- 줄 안의 `$…$` · `` `…` `` 은 통째로 빼 뒀다가 되돌림 → **수식 안에서는 절대 안 나뉨**

### 앞머리 유지

- `- ` · `1. ` · `> ` · `(1) ` 같은 앞머리는 떼어 두고 뒷글만 나눔 →
  글머리표(`<li>`)가 풀리지 않음. 나눔은 `<br class="sbr">` 로 들어감.

## 3. 손으로 조절하기

콘솔에서 바로 먹음.

```js
sbrSet(34, 58);   // (최소 길이, 긴 줄 기준) — 더 잘게 = sbrSet(28, 44)
sbrOff();         // 이번 화면에서만 끄기
sbrOn();          // 되돌리기
```

## 4. 확인한 것

- 글머리표 안에서 나뉘어도 `<ul><li>` 유지됨.
- `$I=\dfrac{P}{V}$` 처럼 수식 낀 줄 — 수식 원형 그대로, 수식 밖에서만 나뉨.
- `2.7미터` · `KEC 241.17` · `3.` 번호 — 안 나뉨.
- 표 줄 · `$$…$$` 블록 — 그대로.

---

## 5. 세제곱근이 «√[3]» 으로 깨지던 것

- 뿌리: 수식 밖 LaTeX 명령을 글자로 바꾸는 `fixTex()` (붙인그림 조각 안).
  수식 자리를 `\$[^$]*\$` 로만 잡아서, `$$…$$` 를 **빈 `$$` 두 개**로 읽음 →
  가운데 식 전체가 «수식 밖» 취급됨.
- 그래서 `\sqrt[3]{…}` → `√[3]{…}`, `\times` → `×` 로 바뀌어 KaTeX 에 들어감.
  `\sqrt{3}` 은 `√{3}` 으로 바뀌어도 얼추 비슷하게 보여서 여태 안 드러났음.
- 고침: `$$…$$` · `\[…\]` · `\(…\)` 를 먼저 잡아 통째로 건너뜀.
  수식 밖 `0.36 [\Omega]` → `[Ω]` 바꿔 주던 원래 일은 그대로 함.
- 문제·답안(`mdRich`)도 같은 함수를 타므로 같이 고쳐짐.

## 6. NOT 윗줄(`\overline`)이 이어지거나 겹치던 것

그리기 직전 한 곳(v264 KaTeX 손질 자리)에 ④ `bars()` 추가 → 해설·문제·답안 전부 먹음.

| 증상 | 손질 |
|---|---|
| `\overline{A}\overline{B}` 윗줄이 한 줄로 이어져 `\overline{AB}`(NAND)로 읽힘 | 나란한 윗줄 사이 `\mkern2.5mu` |
| 겹친 윗줄(`\overline{\overline{A}+B}`) 사이 틈이 1~2px → 굵은 한 줄로 보임 | 바깥 윗줄을 겹수만큼 띄움(`\rule{0pt}{…em}`) |
| `\bar{AB}` 가 짧은 꺾쇠로만 뜸 | 글자 둘 이상이면 `\overline` 으로 |
| 유니코드 윗줄 `A̅B̅` 가 글자마다 따로 끊김 | 이어 쓴 것은 `\overline{AB}` 하나로 (수식 안·밖 둘 다) |
| 겹친 윗줄 위쪽이 잘리거나 윗줄 글과 겹침 | `.katex-display:has(.overline)` 위 여백, 겹친 줄 있는 문단 줄간격 2.2 |

- 이미 `\,` · `\cdot` 로 띄운 것은 안 건드림. 두 번 돌려도 같은 결과.
- 줄 나눔(sbr)도 `\(…\)` · `\[…\]` 안은 안 나누게 막음.
