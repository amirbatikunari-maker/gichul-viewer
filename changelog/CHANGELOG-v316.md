# v316 — 법규·표 «정해진 값» 문제가 원칙 미달로 튕기던 것

## 증상
- KEC 341.7 (아크 기구 이격거리 → 1[m]) 같은 문제에서 «Sonnet 해설이 원칙에 못 미칩니다» 창
- 답이 «1[m]m» 처럼 단위가 두 번

## 원인
- 답에 숫자가 있다고 AI 가 «표·선정/계산» 으로 분류 → 계산형은 «식 네 줄» 필수 → 계산할 게 없는 문제라 매번 미달
  → 다시 받기 두 번 + 작은 틀 + (Opus 면 Sonnet 까지) 부르고도 실패

## 고침 (워커 v316)
- 분류 규칙: 법규·KEC·기술기준·표에 **정해진 값** 을 쓰는 문제는 숫자가 답이어도 **단답**
  - 표·선정은 «먼저 계산한 값» 으로 표에서 고르는 문제만
- 그래도 계산형으로 오면 자동으로 단답으로 바로잡음
  - 조건: 풀이에 부호식·숫자대입식이 하나도 없고, 주어진 값에 숫자 든 줄이 2개 미만
  - 이때 최소 답안·단계별 답이 비어도 다시 받지 않음(보충만)
  - 진짜 계산 문제(주어진 값에 숫자가 여럿)는 예전처럼 식 네 줄을 요구
## 고침 (화면)
- 답과 단위가 모양만 다르고 같은 단위면(1[m] + \mathrm{m}) 또 붙이지 않음
